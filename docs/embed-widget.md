# Embedding the digest widget on a partner site

The widget shows the latest public issue of a project and a subscribe form. It runs in an iframe
from our domain, so the partner page needs one snippet and no build step.

## Before you start

The project owner must add your site to the project first: **Research projects → Embedding →
Embed partners**. Each partner has a name, a key (lowercase letters, digits and dashes, 2-32
characters), and one or more exact **origins** such as `https://curehht-ru.org`. Until your origin
is on that list, the widget does not render on your site and only your fallback block is shown.

The admin shows ready-to-paste snippets for every saved partner, in Russian and English.

## What the widget shows

- the date and summary points of the latest public issue, and the first N items
  (title, a plain-language sentence, a link to the item page);
- a link to the full issue and to all issues;
- a subscribe form (email, language, consent), or a button that opens the subscribe page;
- the medical disclaimer and the "generated by AI" label, always.

Hidden issues never appear. A new or hidden issue shows up within minutes. The widget is cached
for at most one hour.

## Script snippet (recommended)

```html
<div
  data-digest-widget
  data-project="hht"
  data-partner="curehht-ru"
  data-locale="ru"
  data-items="3"
  data-theme="auto"
  data-subscribe="form"
>
  <p>
    Новости исследований простым языком.
    <a href="https://vk.com/club1">Сообщество</a> ·
    <a href="https://hht.rarediseasedigest.org/ru/projects/hht?src=site:curehht-ru#subscribe"
      >Подписаться</a
    >
  </p>
</div>
<script async src="https://hht.rarediseasedigest.org/embed/v1.js"></script>
```

The script inserts an iframe, resizes it to its content, and follows the page's light or dark
preference. One script tag serves every container on the page; pasting it twice is harmless.

| Attribute            | Required | Values                                    | Default | If invalid     |
| -------------------- | -------- | ----------------------------------------- | ------- | -------------- |
| `data-digest-widget` | yes      | (presence)                                | -       | ignored        |
| `data-project`       | yes      | project slug                              | -       | fallback stays |
| `data-partner`       | yes      | the partner key set by the owner          | -       | fallback stays |
| `data-locale`        | no       | `en` `de` `tr` `ru` `uk`                  | `en`    | `en`           |
| `data-items`         | no       | integer 1-20                              | `3`     | `3`            |
| `data-theme`         | no       | `auto` `light` `dark`                     | `auto`  | `auto`         |
| `data-subscribe`     | no       | `form` (in the frame) or `link` (new tab) | `form`  | `form`         |

If the container is empty, `data-fallback-text` and `data-fallback-href` (an `https:` URL) build a
one-line fallback.

## Fallback markup

The markup inside the container is **yours** and stays on the page. It is shown until the widget is
ready, and kept if the widget never is. Write it in your page's language:

```html
<!-- Russian -->
<p>
  Новости исследований простым языком. <a href="https://vk.com/…">Сообщество</a> ·
  <a href="…#subscribe">Подписаться</a>
</p>
<!-- English -->
<p>
  Plain-language research news. <a href="https://vk.com/…">Community</a> ·
  <a href="…#subscribe">Subscribe</a>
</p>
```

## Plain frame snippet

For sites that do not allow third-party scripts:

```html
<iframe
  src="https://hht.rarediseasedigest.org/embed/ru/hht/curehht-ru/auto-3-form"
  title="Новости исследований: последний выпуск"
  width="100%"
  height="900"
  style="border:0"
  sandbox="allow-scripts allow-same-origin allow-forms allow-popups allow-popups-to-escape-sandbox"
  loading="lazy"
></iframe>
```

The height is fixed, so the widget scrolls inside the frame when its content is taller. The path
is `/embed/{locale}/{project}/{partner}/{theme}-{items}-{mode}`. If our domain is blocked, the
browser shows its own error, which is why the script snippet is recommended.

## When our site is unreachable

The loader waits 10 seconds for the widget. If it does not answer (our domain is blocked, the
origin is not allowed, the project or partner is unknown, or the server is down), the frame is
removed and your fallback block stays visible. The page never shows a broken frame or an endless
spinner.

## Privacy

The widget sets no cookies and uses no trackers or storage. The loader is under 3 KB and has no
dependencies. A subscription stores only email, language, consent and the source `site:<key>`.

## For spec 013 (period reviews)

Spec 013 sets `periodReview` in `loadEmbedModel` (`apps/web/src/lib/embed/loadEmbedModel.ts`) and
calls `revalidateEmbed(projectId)` when a review is published or hidden. Nothing else in the
widget changes.

## Launch checklist for production

Production is `https://hht.rarediseasedigest.org`, and the project slug there is `hht` (the
`hht-research` slug is only the local seed).

1. Apply the `source` column change first: [`docs/migrations/014-embed-source.md`](migrations/014-embed-source.md).
2. Merge and deploy. Check that `https://hht.rarediseasedigest.org/embed/v1.js` answers 200.
3. Check that Vercel has `PUBLIC_SITE_URL=https://hht.rarediseasedigest.org` (no trailing slash) and
   `PAYLOAD_API_KEY`. The widget uses them to refresh its cache after a background translation.
4. In the admin, open the project **hht → Embedding → Embed partners** and add the partner, for
   example name `curehht-ru.org`, key `curehht-ru`, origin `https://curehht-ru.org`, and the VK
   community URL as the fallback link. Save.
5. Copy the Russian script snippet from the same page into the partner's news page.
6. Open the partner page. Expect the widget to render and resize. Then open the widget URL
   directly, `https://hht.rarediseasedigest.org/embed/ru/hht/curehht-ru/auto-3-form`, and check
   the response header `content-security-policy: frame-ancestors https://curehht-ru.org`.
7. Check reachability from Russian residential and mobile networks without a VPN (open question
   Q1 in the spec). If the widget stays empty there, the fallback block is what readers see.
